About The Project
Sopan 1.0 is a smart irrigation solution designed to empower the farmers of Sikkim. Our goal is to provide a low-cost, accessible, and intuitive system that uses LoRaWAN-enabled soil sensors to automate watering. This dashboard is the user-facing interface for the farmer, built with simplicity and clarity as our top priorities.

We believe that technology should be an aid, not a burden. Therefore, we've replaced complex graphs and numbers with simple, color-coded visual indicators that are instantly understandable, regardless of technical literacy.

Key Features
🎨 Intuitive Visual Indicators: The dashboard immediately communicates the status of soil, weather, and the water valve using large icons and a simple color system (e.g., Red for "Dry," Green for "Optimal").

🌐 Multi-Language Support: The entire interface can be switched between English, हिन्दी, and नेपाली to ensure it is accessible to all farmers.

🕹️ Dual-Mode Control:

Automatic Mode: The system intelligently controls the water valve based on live soil moisture data.

Manual Mode: The farmer can instantly override the system and take direct control of the water valve with simple ON/OFF buttons.

⚙️ Farmer-Controlled Settings: A simple settings panel allows the farmer to adjust the automatic thresholds for "Dry" and "Wet" conditions, tailoring the system to their specific crops and soil types.

📊 Optional Data History: For those who want more detail, a "View History" button reveals a graph of soil moisture over time, allowing for deeper trend analysis.
